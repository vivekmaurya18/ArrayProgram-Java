# Decrement Array Value Program in Java

## Description
This Java program takes array elements as input from the user and decreases each element by `1`.

---

## Features
- User input using Scanner
- Array creation in Java
- Method usage
- Array element decrement operation
- Output updated array

---

## Java Concepts Used
- Arrays
- Methods
- Loops (`for` loop)
- Scanner class
- User input handling

---

## Program Flow
1. User enters array size.
2. Program creates an integer array.
3. User enters array elements.
4. Method decreases every element by `1`.
5. Updated array is displayed.

---

## Important Array Declaration

```java
int arr[] = new int[n];
```

### Explanation
- `int` → data type
- `arr[]` → array name
- `new int[n]` → creates array of size `n`

Example:

If `n = 5`

Then array indexes are:

```java
arr[0], arr[1], arr[2], arr[3], arr[4]
```
## Sample Input

Enter size of array:
5

Enter array elements:
10 20 30 40 50

## Sample Output

After decrement:
9 19 29 39 49

## Time Complexity

O(n)

Because the loop runs `n` times.
